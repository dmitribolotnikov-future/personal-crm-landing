# Лендинг «Личная CRM»

Одна статичная страница. Все кнопки ведут в приложение: `https://app.lichnocrm.ru`.

## Как запустить у себя

Нужны Node.js и pnpm.

```sh
pnpm install   # один раз: скачать зависимости
pnpm dev       # открыть черновик на http://localhost:4321 - обновляется при каждом сохранении
pnpm build     # собрать готовый сайт в папку dist/
pnpm preview   # посмотреть собранный сайт на http://localhost:4321
```

## Где что лежит

- `src/config.ts` - адрес приложения, куда ведут кнопки
- `src/styles/tokens.css` - цвета, шрифты, размеры текста, отступы, скругления
- `src/components/` - блоки страницы: шапка, первый экран, «Проблема», «Решение», «Выгода», финальный блок
- `public/` - значок сайта во вкладке браузера и на экране «Домой» iPhone
- `astro.config.mjs` - настройки сборки и шрифтов (Onest и JetBrains Mono скачиваются при сборке и отдаются с нашего сервера)
- `design/` - макет, по которому сделана страница
- `.github/workflows/deploy.yml` - выкатка на сервер

## Как выкатывается

Каждый push в `main` сам выкатывает сайт на https://lichnocrm.ru:

1. GitHub Actions собирает сайт (`pnpm build`) - на сервере ничего не собирается.
2. Папка `dist/` копируется на сервер в `/var/www/lichnocrm.ru` через `rsync --delete`: лишние старые файлы удаляются.
3. Проверка: главная отвечает 200 и отдаёт ровно ту страницу, что сейчас собрана. Если нет - запуск красный.

Ход выкатки - вкладка Actions на GitHub. Стенда и отката нет: сломалось - правим и пушим новую версию.

На сервер заходит отдельный пользователь `landing-deploy`. Его ключ разрешает только загрузку файлов в папку лендинга - ни команд, ни чтения.
Ключ лежит в секрете `DEPLOY_SSH_KEY`, адрес сервера, пользователь и отпечаток сервера - в переменных `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_KNOWN_HOSTS` (Settings → Secrets and variables → Actions).
