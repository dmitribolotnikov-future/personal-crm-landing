# Лендинг «Личная CRM»

Одна статичная страница. Все кнопки ведут в приложение: `https://app.lichnocrm.ru`.

## Как запустить у себя

Нужны Node.js и pnpm.

```sh
pnpm install   # один раз: скачать зависимости
pnpm dev       # открыть черновик на http://localhost:4321 - обновляется при каждом сохранении
pnpm build     # собрать готовый сайт в папку dist/
pnpm preview   # посмотреть собранный сайт на http://localhost:4321
```

## Где что лежит

- `src/config.ts` - адрес приложения, куда ведут кнопки
- `src/styles/tokens.css` - цвета, шрифты, размеры текста, отступы, скругления
- `src/components/` - блоки страницы: шапка, первый экран, «Проблема», «Решение», «Выгода», финальный блок
- `public/` - значок сайта во вкладке браузера и на экране «Домой» iPhone
- `astro.config.mjs` - настройки сборки и шрифтов (Onest и JetBrains Mono скачиваются при сборке и отдаются с нашего сервера)
- `design/` - макет, по которому сделана страница
